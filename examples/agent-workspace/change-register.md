# Approved policy change register

Original authored fictional fixture, MIT licensed. No real customer data.

Change ID: RET-2026-09. Approved by the Customer Operations owner on 2026-08-25.
Effective for purchases on or after 2026-09-01.

Return Policy v3 supersedes Return Policy v2 and the 30-day rule quoted in the
2025 support handbook for purchases on or after that effective date. The approved
v3 window is 14 days. The support handbook is retained for historical reference
and must not override v3 for these newer purchases.

Transition: purchases before 2026-09-01 retain the v2 30-day window. Both versions
waive a restocking fee for otherwise eligible unopened returns. No change to the
requirement for proof of purchase was approved.

When documents conflict, this signed change register establishes which version
applies. There is no blanket extension for customers who read the old handbook;
any discretionary exception requires a separate human approval.
